# B 模块工作说明与验收入口

工作分支：`codex/b-relayer`。本分支只实现 B 的后端与执行协调职责，PR 等项目负责人同意后再创建。

## 已实现

- Fastify API：接收签名意图，查询意图、历史状态、批次和运行指标。
- EIP-712 结构、domain、签名者、地址、整数和有效时间校验。
- SQLite 持久化队列、永久 nonce 内容预留、重复提交幂等处理。
- 数量阈值／等待超时合批；按批内顺序预模拟，gas 超限时拆分。
- 交易先签名落库再广播，明确回滚后有限重试。
- 未知交易结果进入 RECONCILING；同一原始交易有限重播，结果不明时阻止新交易。
- 成功回执必须包含准确的全部 intentId，不能仅凭 tx 成功或 nonce 已使用就确认。
- 独立的模拟链适配器与真实 ethers/EVM 适配器。
- 基础指标与测试，保留失败交易 gas；接口不暴露私钥、签名或原始交易。

## 启动

在仓库根目录使用 Node 22.23.1：

```bash
npm ci --ignore-scripts
npm run check
cp .env.example .env
npm run dev
```

另开终端执行 `npm run demo`，会提交 12 个签名意图并等待模拟确认。默认地址是 `http://127.0.0.1:3000`。日常运行不需要安装钱包、配置真实密钥或使用真实资产。

## 测试边界

测试包含 API、队列、重复提交、过期、gas 拆批、回滚、丢失回执、重启恢复和异常配置。此外，测试会启动本地 Anvil，用一个专门的 Solidity 接口测试合约验证真实签名、交易广播、回执解析和回滚。

该测试合约不具备 A 的授权、ERC-20 转账或累计预算逻辑。因此，“B 的 EVM 传输已验证”不等于“整个课程项目的资金安全和合约功能已验证”。模拟模式也不代表真实 LLM、真实转账或真实性能测量。

## 需要其他成员确认

| 成员 | 需要对齐的内容 |
|---|---|
| A | 正式合约 ABI、tuple 顺序、domain、事件 indexed 字段、授权和 Agent 查询方式 |
| C | SDK 的签名 digest、整数单位、nonce 分配及请求结构 |
| D | pending / confirmed / failed / reconciling 状态、分页、模拟模式提示 |
| E | 实验 runId、时间窗口、初始状态、失败率分母及真实链性能实验 |

`GET /agents?owner=...` 当前明确返回 501，等待 A 的注册接口和索引约定；不会伪造授权状态。真实 EVM 模式需要显式设置 `EVM_ABI_CONFIRMED=true`，表示已经人工核对 A/B/C 的协议一致。

## 恢复和限制

- 单个进程、单个数据库、最多一笔未决交易。
- 正常停止会移除 `.lock.pid`；异常退出后，先确认记录的进程已经停止，再删除失效锁并重启。不要删除数据库或模拟链账本来“清空错误”。
- 自动重播次数用完后继续查回执，但保持发送阻塞。没有自动提价、替换 nonce、多进程接管或公链重组回滚。
- FAILED 只表示后台停止重试，不会使链上签名失效；撤销权限需要 Owner 在合约执行。
- 模拟 gas 是固定公式，不能用于课程性能结论。当前指标接口是累计快照，正式对照实验由 E 设计采样窗口和负载。
- SQLite 在 Node 22 中会提示实验性警告；当前版本和测试环境已在项目中锁定。

完整接口和参数见 `services/relayer/README.md`；A/C/D/E 交接清单见 `docs/b-handoff.md`。
